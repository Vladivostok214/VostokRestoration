## Contexto Confirmado

Tras la implementación de P1.10C y la validación mediante QA Manual, el benchmark arrojó:

```text
Precision Global = 93.94%
Recall Global    = 86.11%
F1 Global        = 89.86%
```

El detector Pop mejoró:

```text
Precision:
62.5% → 71.4%
```

sin regresiones observables.

Sin embargo, permanecen dos anomalías residuales:

### Caso A

```text
VOS-17
Pop
30.883s
```

Permanece como Falso Positivo.

La hipótesis actual es que el margen de clipping implementado:

```text
2048 muestras (~46 ms)
```

es insuficiente para absorber el transitorio precursor.

---

### Caso B

```text
GT-032
Tipo real: Click
Detectado: Pop
```

Permanece como Error de Tipo.

La hipótesis actual es que existe una condición específica en la frontera Click ↔ Pop que impide que el evento sobreviva como Click a pesar de poseer una amplitud extremadamente alta.
