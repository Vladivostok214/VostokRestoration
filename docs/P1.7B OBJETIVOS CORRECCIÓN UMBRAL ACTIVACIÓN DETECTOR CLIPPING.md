# VOSTOK DSP LAB - P1.7B

  # CORRECCIÓN DEL UMBRAL DE ACTIVACIÓN DEL DETECTOR DE CLIPPING

  Contexto:

  La auditoría P1.7A identificó la causa exacta del fallo del detector de Clipping.

  Hallazgos confirmados:

  GT-008:

  * Peak máximo = 0.8211
  * Threshold actual Rust = 0.84
  * Candidatos encontrados = 0

  GT-013:

  * Peak máximo = 0.7863
  * Threshold actual Rust = 0.84
  * Candidatos encontrados = 0

  Diagnóstico:

  El detector no falla en la detección geométrica.

  El detector nunca llega a ejecutar la lógica de detección porque la condición inicial:

  if val >= limit

  descarta todos los candidatos antes de analizar:

  * flat-tops
  * count >= 2
  * tolerancia de meseta

  La auditoría confirmó que existen:

  * muestras saturadas
  * flat-tops reales
  * regiones válidas de clipping

  pero ninguna supera el umbral rígido actual:

  limit = 0.84

  ---

  OBJETIVO

  Corregir únicamente el mecanismo de activación del detector de clipping.

  NO rediseñar el detector.

  NO modificar la lógica geométrica existente.

  NO modificar:

  * tolerance
  * count >= 2
  * búsqueda de mesetas
  * consolidación
  * matching

  Mantener intacto todo lo que ocurre después de encontrar un candidato.

  ---

  REQUISITOS

  ## 1. Sustituir el umbral rígido

  Actualmente:

  limit = 0.84

  Este valor debe dejar de ser una constante fija.

  ---

  ## 2. Implementar umbral híbrido

  IMPORTANTE:

  NO utilizar directamente:

  limit = local_peak * 0.95

  porque podría volver extremadamente sensible al detector en archivos de baja amplitud.

  Ejemplo problemático:

  peak = 0.30
  limit = 0.285

  Eso permitiría analizar regiones normales de audio que jamás deberían considerarse clipping.

  ---

  Diseñar un mecanismo híbrido que combine:

  * nivel absoluto mínimo razonable
  * nivel relativo respecto al pico real del archivo

  Objetivo:

  Adaptarse a archivos que hayan sido normalizados o atenuados después del clipping.

  Sin convertir cualquier cresta normal en candidata.

  ---

  ## 3. Instrumentación temporal

  Agregar logs de depuración para validar:

  local_peak
  limit_final
  peak_candidato
  samples_clipped
  flat_top_length

  Los logs pueden quedar protegidos por modo debug.

  Responder:

  Justificar técnicamente la respuesta.
