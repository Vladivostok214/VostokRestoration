# VOSTOK DSP LAB - P1.7D

  # AUDITORÍA DEL FLUJO SCANPARAMS → TAURI → DSP

  Contexto:

  La auditoría P1.7C encontró evidencia fuerte de que el detector de clipping podría estar siendo deshabilitado antes de llegar al backend DSP.

  Hallazgos previos:

  Backend:

  ```rust
  GlitchType::Distortion
  ```

  Serialización:

  ```json
  "distortion"
  ```

  Benchmark:

  ```python
  "distortion" -> "Clipping"
  ```

  (El benchmark ya corrige correctamente la nomenclatura.)

  Además, en:

  ```javascript
  src/hooks/useGlitchManager.js
  ```

  se encontró:

  ```javascript
  const [scanParams, setScanParams] = useState({
    clicks: true,
    hum: true,
    hiss: false,
    dropouts: true,
    distortion: false,
  });
  ```

  Y en la UI visible actualmente sólo aparecen:

  * Clicks & Pops
  * Signal Dropouts
  * Powerline Hum
  * Background Hiss

  No existe ningún control visible para:

  * Distortion
  * Clipping
  * Clip

  ---

  OBJETIVO

  Determinar con evidencia definitiva si el detector de clipping está siendo ejecutado realmente durante un análisis normal.

  Seguir el valor de:

  distortion

  desde React hasta Rust.
