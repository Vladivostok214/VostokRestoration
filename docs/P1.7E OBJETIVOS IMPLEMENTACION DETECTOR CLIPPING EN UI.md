# VOSTOK DSP LAB - P1.7E

  # HABILITACIÓN DEL DETECTOR DE CLIPPING EN LA UI

  Contexto:

  La auditoría P1.7D confirmó que:

  * detectar_clipping() existe y funciona.
  * El detector nunca se ejecuta porque params.distortion llega siempre en false.
  * La UI actual no ofrece ningún control para activar esta bandera.
  * Todos los benchmarks históricos fueron ejecutados con el detector de clipping deshabilitado.

  Objetivo:

  Implementar una solución arquitectónicamente correcta para exponer el detector de clipping al usuario.

  NO modificar la lógica DSP.

  NO modificar detectores.rs.

  NO modificar umbrales.

  NO modificar benchmark.

  Únicamente corregir la capa UI / estado React.

  ---

  REQUISITOS

  ## 1. Agregar Toggle Visible

  Agregar un control visible junto a:

  * Clicks & Pops
  * Signal Dropouts
  * Powerline Hum
  * Background Hiss

  Nuevo control:

  * Clipping / Distortion

  Debe seguir exactamente el mismo patrón visual y arquitectónico que los demás detectores.

  ---

  ## 2. Conectar con scanParams

  Al activarse:

  ```javascript
  scanParams.distortion = true
  ```

  Al desactivarse:

  ```javascript
  scanParams.distortion = false
  ```

  Verificar que el estado viaje correctamente hasta Tauri.

  ---

  ## 3. Mantener Compatibilidad

  No renombrar:

  ```rust
  GlitchType::Distortion
  ```

  No modificar:

  ```rust
  ScanParams.distortion
  ```

  Mantener compatibilidad total con:

  * Backend Rust
  * Serialización JSON
  * Reportes TXT
  * Benchmark evaluator

  ---

  ## 4. Instrumentación Temporal

  Agregar logs temporales para validar:

  Frontend:

  ```javascript
  console.log("SCAN PARAMS", scanParams);
  ```

  Backend:

  ```rust
  println!("DISTORTION ENABLED: {}", params.distortion);
  ```

  Confirmar mediante evidencia que el valor llega correctamente.

  ---

  ## 5. Validación Funcional

  Ejecutar una prueba completa.

  Demostrar:

  1. Toggle activado.
  2. Payload enviado.
  3. params.distortion = true en Rust.
  4. detectar_clipping() ejecutado.
  5. Eventos DISTORTION presentes en el reporte.

  ---

  ENTREGABLES

  1. Archivos modificados.
  2. Diff resumido.
  3. Captura o evidencia de logs.
  4. Confirmación de que detectar_clipping() se ejecuta.
  5. Ejemplo de evento DISTORTION generado.

  IMPORTANTE:

  No realizar optimizaciones DSP.

  No modificar algoritmos.

  Esta tarea corrige exclusivamente una desconexión entre UI y backend descubierta por P1.7D.
