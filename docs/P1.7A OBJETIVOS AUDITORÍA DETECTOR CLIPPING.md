# VOSTOK DSP LAB - P1.7A

  # AUDITORÍA FORENSE DEL DETECTOR DE CLIPPING

  Contexto:

  La investigación P1.6A demostró que el generador original de clipping era defectuoso.

  La implementación P1.6B corrigió el problema:

  * Se generan muestras realmente saturadas.
  * Existen flat-tops verificables.
  * Se validan samples_clipped antes de registrar Ground Truth.
  * Se eliminaron discontinuidades artificiales.

  Tras corregir el generador y repetir el benchmark:

  Clipping:

  * TP = 0
  * FP = 0
  * FN = 2
  * Recall = 0%

  Esto indica que ahora existe clipping real en el banco de pruebas, pero el detector de Clipping sigue sin reportarlo.

  ---

  OBJETIVO

  Determinar exactamente por qué detectar_clipping() no captura los dos eventos de clipping reales presentes en el benchmark.

  NO IMPLEMENTAR CAMBIOS.

  NO MODIFICAR detectores.rs.

  NO AJUSTAR UMBRALES.

  Primero demostrar con evidencia qué condición está fallando.

  PASA / FALLA
