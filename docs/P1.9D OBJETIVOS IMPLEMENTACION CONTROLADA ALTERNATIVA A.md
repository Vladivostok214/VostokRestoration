## Contexto Confirmado

P1.9C concluyó que la principal causa de pérdida de Recall del detector de Clicks es la regla de Firma Física Estricta:

```rust
if entry_change.signum() == exit_change.signum() {
    continue;
}
```

El análisis demostró que múltiples Falsos Negativos reales presentan:

```text
entry_change ≈ ±1.0
exit_change  ≈ ±0.001 ... ±0.02
```

compartiendo signo únicamente porque el click ocurre montado sobre una pendiente lenta de voz o Hum.

La recomendación seleccionada fue:

**Alternativa A - Relajación Controlada por Asimetría de Magnitud**

## Implementación Requerida

Localizar la lógica actual:

```rust
if entry_change.signum() == exit_change.signum() {
    continue;
}
```

Implementar una excepción basada en asimetría de magnitud.

Objetivo conceptual:

Si ambos gradientes tienen el mismo signo PERO:

```text
|entry_change| >> |exit_change|
```

el evento no debe descartarse automáticamente.

La implementación exacta queda a criterio técnico del análisis de P1.9C, pero debe respetar el espíritu de la Alternativa A.
