## Contexto

LAB-DROPOUT-003 identificó un falso positivo persistente:

```text
[VOS-33] Dropout | 101.647s
```

La auditoría inicial concluyó que el evento ocurre aproximadamente 33 ms antes del final físico del archivo:

```text
Duración WAV ≈ 101.680s
Evento ≈ 101.647s
```

Hipótesis principal actual:

El detector está confundiendo el fin natural del archivo (EOF) con un dropout legítimo debido al bloque residual ejecutado después del bucle principal cuando:

```rust
inside_dropout == true
```
